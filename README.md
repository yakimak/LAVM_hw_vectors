Репозиторий с геометрическими задачами на Python
Этот репозиторий содержит решения трех задач, связанных с геометрическими вычислениями в 2D и 3D пространстве.

Содержание
Определение видимости в поле зрения камеры (camera_fov.py)

Проверяет, находится ли персонаж в поле зрения камеры

Использует векторную математику и углы обзора

Определение направлений стрельбы космического корабля (ship_weapons.py)

Вычисляет 3 ортогональных направления стрельбы

Основано на векторном произведении в 3D пространстве

Поворот космического корабля в 2D пространстве (ship_rotation.py)

Поворачивает треугольник (корабль) на заданный угол

Использует матрицу поворота
